# projeto-clinica-veterinaria
Website fictício de uma clínica veterinária criado para praticar HTML5 e CSS3, abordando estrutura semântica, formulários, tabelas, imagens e organização de páginas.
# 🐾 Clínica Veterinária PetLife

Projeto desenvolvido durante meus estudos de HTML e CSS.

## 📋 Sobre

Este projeto simula o site institucional de uma clínica veterinária fictícia, contendo informações sobre a empresa, horários de atendimento e uma página de contato.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 📄 Páginas

- Página Inicial
- Sobre a Clínica
- Horário de Atendimento
- Contato

## ✨ Recursos utilizados

- Estrutura semântica
- Formulários HTML
- Tabelas
- Imagens
- Google Maps (iframe)
- Links de navegação

## 🎯 Objetivo

Praticar os conceitos fundamentais de HTML e CSS através da criação de um website completo.
